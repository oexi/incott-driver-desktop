# 抓取官方驱动的 USB 通信（Windows）

官方驱动能做到、本软件做不到时（例如某个按键改不了、某个设置不生效），最直接的证据是官方驱动实际发给鼠标的数据。按下面的步骤录一段，附在 Issue 里即可。

> ⚠️ 抓包会记录所选 USB 设备的全部通信。**只勾选接收器或鼠标**；抓包期间不要用键盘输入密码等内容。

## 1. 安装

安装 [Wireshark](https://www.wireshark.org/download.html)，安装过程中勾选 **USBPcap**。装完后重启电脑。

## 2. 只选接收器 / 鼠标

1. 关闭本软件和浏览器里的网页驱动，只打开官方驱动。
2. 打开 Wireshark，接口列表里会有 `USBPcap1`、`USBPcap2`……。点接口左边的齿轮图标，在设备列表里找到接收器（有线时是鼠标），只勾选它。认不出来时，拔下接收器再插上，看哪一项消失又出现。
3. 双击这个接口开始抓包。

## 3. 只做要反馈的那个操作

在官方驱动里**只做你要反馈的操作**，例如把按键 6 改成"DPI 循环"并应用。多个操作之间等 2 秒以上，并记下做了什么、按什么顺序。

## 4. 保存并上传

点红色方块停止，选 **文件 → 另存为**，保存为 `.pcapng`。压缩成 `.zip` 后拖进 Issue，并写上做了哪些操作。

## 自己先看一眼（可选）

在显示过滤栏输入 `usb.bmRequestType == 0x21`，剩下的就是驱动发给鼠标的 SET_REPORT 命令。数据部分以 `09` 开头的 9 个字节（`09` 是 Report ID，后面 8 字节是命令）和本软件诊断信息里 `F>` 开头的记录是同一种格式，可以直接对照。
